# fiscal-flow — Documentação de negócio

## O que resolve
MEI/PME afogado em nota fiscal. Lê XML de NF-e/NFC-e, categoriza despesas e
exporta CSV pro contador — 100% no navegador (privacidade = argumento de venda).

## Como gera receita
- Freemium: grátis até 20 notas/mês; plano pago acima.
- Fechamento mensal assistido (serviço).
- Custo de infra zero (estático).

## Demonstração
Botão "Carregar nota de exemplo" no index.html, para testar sem arquivo real.
